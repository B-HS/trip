- 목적지: `country_code` 는 `shared/constant/countries.ts` 의 `COUNTRIES`(alpha-2 → 한국어·영어 이름 + 대표 좌표) 키다. 항공편이 없는 트립의 지구본 경로는 `departure_airport_code ?? HOME_AIRPORT_CODE`(ICN) → 목적지 순서로 나라 좌표를 이어 그린다(ADR-0035). 출발 공항은 트립별 값이고 `null` 이면 ICN 으로 계산하므로 backfill 은 하지 않았다.
- 즐겨찾기: 사용자별로 트립을 셸 레일에 고정한다. 트립 삭제·사용자 삭제 시 FK 로 cascade 삭제된다.
- 파생 렌더: 배지 라벨·색·여유 문구는 항목의 `kind_id` 가 가리키는 `trip_schedule_kind`(`buffer_note` → 종류 `buffer_label` → 없음) 에서 온다(ADR-0025). 지도 링크는 `buildMapUrl(map_query)`. 전체 일정 표는 `day.*_summary` 에서 생성.
- 날짜는 `DATE`(string 모드, `YYYY-MM-DD`), 시각 라벨은 자유 문자열(원본이 "체크인 후" 같은 비정형 값을 쓴다).
- 마이그레이션: `bun run db:generate` → `bun run db:migrate`(`drizzle/`, 이력 테이블 `trip___drizzle_migrations`). `drizzle-kit push` 금지. 0006 은 추가 전용(테이블 6·컬럼 9·FK 12·인덱스 7 + 게시판 3행 INSERT), 0007(`0007_absent_santa_claus`)도 추가 전용(`trip_trip.departure_airport_code` ALTER 1개). 0008(`0008_needy_victor_mancha`, ADR-0037) 은 추가 전용(테이블 `trip_report`·`trip_user_block`, post/comment `deleted_at` ADD, `point_ledger.reason` enum 에 `revoked` 추가 MODIFY, FK 4·인덱스 2)이나 **미적용**(이 환경에 `DATABASE_URL` 없음; 적용 후 이력 9행 확인).
- 커뮤니티 카운터(`like_count`·`comment_count`)는 대상 글·트립 행을 `SELECT … FOR UPDATE` 로 잠근 트랜잭션에서 삭제 제외 실제 COUNT 로 동기화한다. `view_count` 만 증분(작성자 본인 조회 제외). 채택은 `accepted_comment_id` 로 글당 1회·변경 가능(ADR-0037): 재채택은 옛 댓글 -10 `revoked` + 새 댓글 +10, 채택 댓글 삭제는 -10 `revoked` + `accepted_comment_id` null. 사용자 읽기는 `deleted_at IS NULL` + 차단자 `NOT IN` 필터(ADR-0037).
- 관리자 지정: `bun run admin:set <email>`(`scripts/set-admin.ts`, role 컬럼).
- drizzle 0.45 `isConfig` 는 `{ client, mode }` 만 있는 설정을 클라이언트로 오인한다 → 스키마 없이 쓸 때는 `logger: false` 를 함께 넘긴다(`scripts/migrate.ts`).
