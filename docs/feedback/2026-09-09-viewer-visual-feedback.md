# 2026-09-09 — 뷰어 시각 피드백 (사용자 지적)

## 무엇을 지적받았나

- "gap 은 없어야지, 지금 디자인 자체가 background 로 영역 분할인데 사이드바랑 content 에 갭이 있네"
- "background 가 잘 분리되어야지, 사이드바랑 컨텐츠 사이에 보더 1px 뭔가 있고, 사이드바랑 컨텐츠의 사이드바 색상이 같잖아"
- "컨텐츠 사이드바에 의미없는 3D 모델 뭐야, 이따구로 넣을 거면 넣지 마"
- "3D 모델들이 안 움직이는데" (OS reduce-motion 설정 때문에 정지)

## 왜 틀렸나

- DESIGN §6-2 의 "content left baseline 256+12" 를 그대로 옮겨 레일과 콘텐츠 사이에 12px 인셋을 두었고, 위젯 사이드바에 레일 토큰(bg-sidebar)을 재사용해 계층이 무너졌다.
- 3D 를 "사용하면 좋은 곳 전부"로 해석해 정보가 없는 위치(뷰어 사이드바 하단)에 장식으로 넣었다.
- 접근성 기본값(prefers-reduced-motion 존중)이 사용자의 명시적 요구(모션 항상 동작)와 충돌했다.

## 어떻게 고치나

- 레일(bg-sidebar) 바로 옆에 콘텐츠 컬럼(bg-background)을 붙이고, 블록은 bg-card, 보조 스트립·표 헤더는 bg-muted. 레일-콘텐츠 사이 심·인셋 없음.
- 3D 는 데이터를 보여주는 곳에만. 장식용 미니 지구본 제거.
- 모션은 앱 내 설정(`use-motion-preference`)으로만 줄이고 OS 설정은 무시.

## 언제 적용하나

- 이 프로젝트의 모든 화면. DESIGN.md 의 픽셀 상수보다 사용자의 "배경으로 영역 분할" 해석이 우선한다.
- 다른 프로젝트에서도 3D·모션 장식은 정보 가치가 있을 때만 넣는다.
