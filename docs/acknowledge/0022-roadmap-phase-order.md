# ADR-0022 — 로드맵 착수 범위와 순서 (2026-09-09)

## 배경

세션 2 에서 사용자가 로드맵 1~10 전부에 대해 착수 여부를 답했다.

## 결정

| 로드맵                                      | 결정 | 비고                                                                                                                                                       |
| ------------------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 사이드바 링크·설명                        | 시작 |                                                                                                                                                            |
| 2 예매 첨부                                 | 시작 | 저장소는 **Cloudflare R2**. 키(`R2_*`)는 사용자가 추후 제공, 없을 때는 업로드 UI 를 비활성화하고 안내                                                      |
| 3 OSM 지도                                  | 보류 | 로드맵에 그대로 남긴다                                                                                                                                     |
| 4 AI 질문답·수정                            | 시작 |                                                                                                                                                            |
| 5 일정 종류 배지                            | 시작 |                                                                                                                                                            |
| 6 커뮤니티                                  | 시작 | YouTube 채널처럼 **커스터마이징 가능한 프로필 대문(배너)** 과 **프로필 사진 업로드**, 표시 이름·소개 편집을 포함(현재 `user.image` 는 컬럼만 있고 UI 없음) |
| 7 인증 확장 등                              | 부분 | **Tiptap 에디터 + YouTube embed 는 지금**, OAuth·이메일 인증·약관은 보류                                                                                   |
| 8 셀형 액션 UI                              | 시작 |                                                                                                                                                            |
| 9 몇박 며칠                                 | 시작 | ADR-0020                                                                                                                                                   |
| 10 SEO·GEO·JSON-LD·Analytics·Speed Insights | 시작 |                                                                                                                                                            |

버그 목록(세션 2 보고 B1~B8)은 전부 처리하되, 편집기 검증 문구 한국어화(B5)는 사용자가 직접 본 뒤 결정하기로 보류. 환경 정리(D 목록)는 하지 않는다.

## 진행 순서(의존성)

1. 버그 B1·B2·B3·B4·B6·B8 + 로드맵 9
2. 로드맵 8 → 1 → 5 (새 화면이 셀 UI 를 쓰도록 8 을 먼저)
3. 로드맵 2 (R2 업로드 기반, 6·7 이 재사용)
4. 로드맵 7(Tiptap·YouTube) → 6
5. 로드맵 4
6. 로드맵 10 (새 공개 페이지가 다 생긴 뒤)

각 단계는 착수 전 정책 ADR 을 추가하고, 단계마다 typecheck·lint·test·build 와 브라우저 확인을 거친 뒤 커밋·push·prod 머지한다.

## 정책 답변(세션 2, 질문 묶음 1~14)

| 번호 | 결정                                                                                                                                              |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | R2 업로드는 서버 경유(Route Handler 검증 후 put), 이미지 3MB 제한                                                                                 |
| 2    | R2 읽기는 공개 버킷·커스텀 도메인(`R2_PUBLIC_BASE_URL`), `next/image` 등록. `r2.dev` 는 개발 전용이라 프로덕션은 사용자가 커스텀 도메인 연결      |
| 3    | jpeg·png·webp·gif·avif, 원본 저장 + `next/image`                                                                                                  |
| 4    | **Vercel Queues 확정**(Pro 플랜 사용 중, 다른 프로젝트에서 이미 사용). 월 3,000 job 기준 1센트 미만                                               |
| 5    | AI SDK 최신(v7) + 프로바이더 패키지(OpenAI·Anthropic, Ollama Cloud 는 OpenAI 호환)                                                                |
| 6    | 무료 한도 없음. 사용자가 자기 키를 등록해야만 AI 사용 가능                                                                                        |
| 7    | 평문 저장 위험을 안내한 뒤 **AES-256-GCM 암호화 유지**. `APP_ENCRYPTION_KEY` 는 사용자가 `.env` 에 직접 생성(값 미기록), Vercel 환경변수에도 등록 |
| 8    | 관리자는 `trip_user.role` 컬럼(better-auth admin 플러그인)                                                                                        |
| 9    | 신고·차단 1차 없음(삭제는 작성자·관리자)                                                                                                          |
| 10   | 답변 포인트 +2, 채택 +10                                                                                                                          |
| 11   | 로그아웃 인트로 유지 + 하단 공개 트립·최근 글 섹션                                                                                                |
| 12   | 공식 `@tiptap/extension-youtube` + 허용 도메인 화이트리스트                                                                                       |
| 13   | 셀형은 `Button` 변형(ADR-0023)                                                                                                                    |
| 14   | 오프셋 페이지네이션 20개 + 제목 검색                                                                                                              |

## 추가 답변(세션 2 후반)

- 단계가 끝날 때마다 **자동으로 push 하고 dev→prod 빨리감기(ff) 머지** 한다(ADR-0009 의 "지시 시" 를 이 로드맵 기간 동안 상시 승인으로 본다).
- DB 의 오사카 예시 트립 `period_note` 도 템플릿과 같이 "예비일 하루" 로 정리한다(자동 계산 "6박 7일" 과 중복 제거).
