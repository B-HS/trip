# ADR-0011 — 배경 계층·보더 없음·셀형 UI (2026-09-09)

## 배경

사용자 지적: "디자인 자체가 background 로 영역 분할", "Border 는 최대한 쓰지 않는다(표 제외)", "사이드바와 콘텐츠 사이드바 색이 같다", "탭·버튼이 패딩 든 것처럼 보인다", "텍스트가 왼쪽에 붙는다", "콘텐츠 사이드바는 전체 높이", "콘텐츠 min-height 는 dvh".

## 결정

- 계층: 레일 `bg-sidebar` → 콘텐츠 사이드바 컬럼 `bg-muted`(그리드 셀 전체 높이, 내부 sticky) → 탭 스트립 `bg-background` 위 활성 탭만 `bg-card`(밑줄·보더·그림자 없음, 높이 12) → 블록 `bg-card`, 블록 사이 1px 심(`gap-px`). 레일-콘텐츠 사이 인셋·심 없음.
- 보더 금지(표 예외): 배지는 `secondary`+틴트, 아코디언·사이드바 구분은 심, 폼 컨트롤은 `bg-muted` + 포커스 링(`shared/ui` 레벨에서 적용).
- 셀형 액션: "완료 숨기기·체크 초기화"는 패딩 없는 셀 버튼. 전면 확대는 로드맵 8.
- 종류 배지는 시간 칸(`bg-card`)에, 오른쪽엔 "지도 열기" 만(높이 h-6 통일). 표는 카드 인셋 없이 꽉 채움. 경로 블록은 `px-4 py-3` 카드.
- 콘텐츠 영역은 dvh 를 채우고 남는 부분은 `bg-card` 채움 블록. 목록 카드는 세로 행.

## 기각된 대안

- DESIGN §6-2 의 12px 콘텐츠 인셋·1px 심: 사용자가 "갭 없어야" 지적.
- 뷰어 사이드바 `bg-sidebar`: 레일과 같은 톤이라 금지.
- 탭 밑줄(shadcn line variant): 편집기에서 콘텐츠와 겹침.
