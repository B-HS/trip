# ADR-0008 — 지구본은 실제 지리, 정보 있는 곳에만 (2026-09-09)

## 배경

1차 구현(와이어프레임 이코스피어, 뷰어 사이드바 미니 지구본)에 "의미 없는 3D" 지적.

## 결정

`world-atlas` land-110m 해안선 + 육지 점 격자 + 위경도선, 공항/나라 좌표 마커, 대권 곡선 경로와 이동 점. 적용처는 인트로 히어로·`/trips` 헤더(전 트립 경로)·빈 상태·404 뿐. 항공편이 없는 트립은 `HOME_AIRPORT_CODE`(ICN) → 목적지 나라 좌표 순서로 체인. 뷰어 사이드바 미니 지구본은 제거.

## 기각된 대안

- 추상 와이어프레임 구체: 지리 정보가 없어 무의미.
- 장식용 배치(사이드바 하단 등): "이따구로 넣을 거면 넣지 마".
- 배경색 오클루더: 표면(bg-card/bg-background)에 따라 색이 틀어져 depth-only 오클루더 채택.
