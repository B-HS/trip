# ADR-0016 — 목적지(나라) 지정·즐겨찾기 레일 (2026-09-09)

## 결정

- `trip_destination`(trip_id·sort_order·country_code alpha-2·city) + `shared/constant/countries.ts`(127개국 한·영 이름, 대표 좌표, 국기 이모지 금지 → 코드 칩). 생성 폼은 나라 ≥1, 편집기 기본 정보 탭에서 정렬 편집. 지구본은 항공편 없으면 ICN→목적지 체인.
- `trip_favorite`(user×trip): 목록 카드 별표(낙관적) ↔ 셸 레일 "즐겨찾기" 목록(`app/(app)/layout.tsx` 프리페치).

## 이유

사용자 요청("나라 지정도", "사이드바에 트립 리스트·즐겨찾기").

## 기각된 대안

- 도시 좌표 지오코딩: 외부 API 필요 → 나라 좌표 + 도시 라벨.
- 사이드바 추가/제거와 즐겨찾기를 별개 개념으로: 하나로 통합(즐겨찾기 = 레일 표시).
