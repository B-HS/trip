# ADR-0021 — JSON 가져오기는 현재 트립 내용을 교체 (2026-09-09)

## 배경

편집기 멤버·공유 탭의 "JSON 내보내기"(`exportTripAction`)만 있고 가져오기가 없어 QA 항목 "같은 JSON 을 가져오기로 되돌릴 수 있다" 를 만족하지 못했다. 사용자가 세션 2 에서 버그·미구현 전부 처리를 지시했다.

## 결정

- 같은 탭에 "JSON 가져오기" 파일 입력을 둔다. 파일을 `tripTemplateSchema` 로 검증하고, 확인 다이얼로그(제목·날짜 수·예매 수 요약, "현재 내용이 모두 교체됩니다") 뒤에 `importTripAction(tripId, template)` 를 호출한다.
- 서버는 한 트랜잭션에서 기본 정보·목적지·항공편·숙소·날짜(하위 행 포함)·예매·정보 섹션을 삭제 후 템플릿으로 다시 넣는다. **공유 설정(`shareSlug`·`isPublic`)·멤버·초대는 유지**한다. 사용자별 체크·메모는 행이 바뀌므로 FK cascade 로 사라진다(다이얼로그에 명시).
- 권한은 `edit`(owner·editor). 완료 후 상세 캐시 무효화와 공유 태그 만료, 성공 toast.

## 이유

"되돌리기" 의미에 맞는 동작은 새 트립 생성이 아니라 현재 트립 교체다. 새 트립을 만들고 싶으면 이미 있는 `createTripFromTemplateAction` 경로를 쓰면 된다(후속으로 새 트립 화면에 파일 입력을 붙일 수 있다).

## 기각된 대안

- 가져오기 = 새 트립 생성만 제공: 공유 링크·멤버가 끊긴다.
- 병합(merge): 행 매칭 규칙이 필요해 범위가 크다.
