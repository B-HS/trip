# ADR-0014 — 오사카 원본은 템플릿 상수 + 시드 + 앱 내 버튼 (2026-09-09)

## 결정

원본 HTML 을 `OSAKA_TRIP_TEMPLATE`(`tripTemplateSchema`)로 전수 이식(7일·65행·16경로·9예매·4정보섹션·참고 35건). `scripts/seed.ts`(`SEED_OWNER_EMAIL` 가입자에게 생성) + 목록/새 트립의 "오사카 예시 트립 만들기". 링크가 2개인 참고 항목 3건은 2행으로 분리.

## 이유

사용자 지시("구조화 끝나면 데이터 넣어줘"). 가입자가 없으면 FK 를 만족할 수 없어 직접 INSERT 는 불가.

## 기각된 대안

- 시드 전용: 첫 로그인 전엔 실행 불가.
- day-note 링크 배열 스키마 변경: 2행 분리가 더 단순.
