# ADR-0033 — 로드맵 확장: OSM 제거, 인증 확장 착수, 커뮤니티 범위 밖 기능 수용, i18n(ko·ja·en) (2026-09-10)

## 배경

세션 3 에서 사용자가 보류·범위 밖 항목의 처리를 다시 정했다. 확인 질문 10건에 전부 추천안으로 답했고, 단계 순서는 메인에 위임했다.

## 결정

### 1. OSM 지도(로드맵 3) 제거

- 로드맵에서 삭제한다. 사유(사용자): 한국법상 지도 데이터를 서버로 경유·가공할 여지가 있으면 사업자(신고) 요건이 붙는다. 지도는 ADR-0006 대로 Google Maps 검색 링크만 유지한다.

### 2. 인증 확장(OAuth·이메일 인증·약관) 착수

- Naver·GitHub OAuth, 이메일 인증(`requireEmailVerification`), 약관·개인정보처리방침 동의(`trip_user_consent`, 버전·시각)를 구현한다. 키·도메인은 사용자가 주는 시점에 실측하며, 그 전에는 R2 와 같은 방식으로 기능을 비활성화하고 안내한다.
- **메일 발송은 Cloudflare**: 이 레포에 `cloudflare/mail-worker/` 를 두고 Worker 의 `send_email` 바인딩으로 발송, Next 서버는 그 Worker 를 API 토큰으로 호출한다. 제품·바인딩 세부는 착수 시 리서치로 확정한다(`[리서치 예정]`).
- 약관 초안은 AI 가 ko 로 작성하고 ja·en 으로 번역해 `docs/legal/` 에 두며, 법령 근거는 `korean-law-mcp`(https://github.com/chrisryugj/korean-law-mcp)로 확인한다. 사용자가 검토 후 확정한다.

### 3. 커뮤니티 범위 밖 기능 전부 수용(ADR-0028·0032 갱신)

- **채택 변경·취소 허용**: 원장에 회수 행(-10, reason `revoked`)을 추가한 뒤 새 댓글에 +10. 글의 `accepted_comment_id` 를 갱신·해제한다.
- **소프트 삭제**: 글·댓글에 `deleted_at`. 목록·카운트·검색에서 제외, 답글이 있는 댓글은 "삭제된 댓글" 자리 유지, 관리자는 복구 가능.
- **댓글 수정**: 작성자만, `updated_at` 갱신·"수정됨" 표시.
- **신고·차단**: 신고(글·댓글·사용자, 사유 선택 + 메모) → 관리자 화면 `/admin/reports` 에서 숨김·삭제·밴(better-auth admin `banUser`) 처리. 사용자 간 차단(`trip_user_block`): 차단한 사람의 글·댓글은 내게 숨김.
- **사용자명 변경**: `/settings/profile` 에서 변경, 중복 검사, 옛 `/u/[username]` 은 404. better-auth `/update-user` 는 계속 닫아 두고 자체 액션으로 처리한다.
- **무한 스크롤은 도입하지 않는다**(ADR-0022 답변 14 유지): 게시판·탐색·프로필 목록은 오프셋 페이지네이션, 댓글은 전부 로드.

### 4. i18n — ko·ja·en

- next-intl. URL 프리픽스는 `as-needed`: 기본 ko 는 프리픽스 없음(`/`), `ja`·`en` 은 `/ja/…`·`/en/…`. 선택은 쿠키로 기억하고 셸 사용자 메뉴·게스트 헤더에 언어 전환 셀을 둔다.
- 범위: UI 문구·검증 메시지·toast·메일 템플릿·메타데이터·약관 전부. 날짜·숫자는 locale 포맷. 사용자 콘텐츠(트립·글)와 오사카 템플릿 데이터는 원문 유지.
- SEO(hreflang·locale 별 sitemap)는 로드맵 10 에서 함께 처리한다.

## 이유

사용자 결정. i18n 을 인증 확장보다 앞에 두어 문구 재작업을 없애고, 커뮤니티 확장을 기본 구현 직후에 붙여 스키마 변경을 한 번의 마이그레이션으로 모은다.

## 기각된 대안

- 무한 스크롤·"더 보기" 병행: 비로그인 SEO 목록과 페이지네이션 이중 구현. 사용자가 미도입(추천안)을 선택.
- 채택 취소만 허용·포인트 회수 없음: 도배 여지.
- 하드 삭제 유지: 복구·신고 처리에 불리.
- 쿠키만으로 locale 결정: SEO 불리. 전 언어 프리픽스: 기존 ko URL 이 바뀐다.
- 사용자명 변경 이력·리다이렉트: 1차 범위 초과.
