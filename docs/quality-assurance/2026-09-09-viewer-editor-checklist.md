# QA 체크리스트 — 뷰어·편집기·셸 (2026-09-09)

> 브라우저에서 직접 확인해야 하는 항목만 모았다. `bun run typecheck` · `bun run lint` · `bun test` 통과는 전제이며, 이 문서의 항목은 통과했다고 대체되지 않는다.
> **모든 항목을 라이트 모드와 다크 모드에서 각각 확인한다.** 테마 전환은 셸 좌측 하단 계정 메뉴의 테마 토글로 한다.
> 확인 방법: 개발 서버(`:3000`)에서 해당 경로를 열고, 필요한 경우 브라우저 확대/축소 대신 창 너비를 실제로 줄여 반응형을 본다.

## 0. 준비

- [ ] 로그인 계정으로 트립이 2개 이상 있고, 그중 하나는 오사카 예시 트립이다
- [x] 그중 하나는 공개 공유(slug)가 켜져 있다 — 세션 2: 오사카 예시 트립 `osaka-qa`(계정에 트립은 1개뿐이라 첫 항목은 미충족)
- [ ] 라이트/다크 각각에서 아래 항목을 1회씩 수행한다

## 1. 배경 계층 (tier)

- [ ] 셸 레일이 `bg-sidebar` 로, 콘텐츠 영역과 명확히 다른 톤이다
- [ ] 레일과 콘텐츠 사이에 1px 심이나 인셋 여백이 없다(색으로만 분리)
- [ ] 콘텐츠 사이드바 컬럼이 `bg-muted` 이고 콘텐츠 영역 전체 높이를 채운다
- [ ] 콘텐츠 블록은 `bg-card` 이고, 블록 사이 구분은 1px 심(배경 비침)이다 — 보더가 그어진 선이 보이지 않는다
- [ ] 마지막 블록 아래가 잘리지 않고 `bg-card` 로 뷰포트 하단까지 채워진다
- [ ] 다크 모드에서 레일·사이드바·카드 세 톤이 서로 구분된다(같은 색으로 뭉개지지 않는다)

## 2. 탭 스트립

- [ ] 탭 스트립 배경이 `bg-background`, 활성 탭만 `bg-card` 다
- [ ] 활성 탭에 밑줄·보더·그림자가 없다
- [ ] 탭 스트립이 좌우 여백 없이 풀블리드로 붙는다
- [ ] 탭 전환 시 인디케이터/콘텐츠 전환 모션이 끊기지 않는다

## 3. 보더 없는 컨트롤 (전역)

- [ ] 입력(Input)·여러 줄 입력(Textarea)·셀렉트가 보더 없이 `bg-muted` 면으로 보인다
- [ ] 포커스 시 보더 색이 변하지 않고 링(ring)만 나타난다
- [ ] 검증 실패(빈 필수값 저장 시도)에서 보더 대신 destructive 링이 보인다
- [ ] 체크박스는 미체크 시 `bg-muted` 사각형, 체크 시 `bg-primary` 이고 모서리가 각지다
- [ ] 스위치는 트랙 `bg-muted` / 켜짐 `bg-primary`, 보더·그림자가 없다
- [ ] 배지(default·secondary·outline)에 보더가 없다 — 배경색으로만 구분된다
- [ ] `outline` 버튼(예: 계정 메뉴의 테마 토글)이 보더 없는 `bg-muted` 버튼이다
- [ ] 표(table)에만 보더가 남아 있다 — 그 외 화면 어디에도 그어진 선이 없다
- [ ] 입력이 사이드바(`bg-muted`) 위에 놓이는 화면이 있다면, 입력면이 배경에 묻히지 않는다

## 4. 날짜 탭 오버플로 + 달력 점프 (`/trips/[id]`)

- [ ] 날짜가 많아 스트립이 넘칠 때만 양끝 화살표 셀이 나타난다
- [ ] 첫/마지막 날짜에서 해당 방향 화살표가 비활성이다
- [ ] 스트립 아래 2px 스크롤 위치 표시가 실제 스크롤과 일치한다
- [ ] 키보드 좌우 방향키로 날짜를 이동할 수 있다
- [ ] "n/총" 카운터를 눌러 달력 팝오버가 열리고, 트립 기간의 날짜만 선택 가능하다
- [ ] 달력에서 날짜를 고르면 해당 날짜 탭으로 점프하고 URL(`?day=`)이 갱신된다
- [ ] 창 너비를 줄였을 때도 화살표·카운터가 겹치지 않는다

## 5. 뷰어 (`/trips/[id]`)

- [ ] 새로고침 시 스켈레톤 없이 완성된 화면이 바로 보인다
- [ ] 일정 체크가 즉시 반영되고(낙관적), 새로고침 후에도 유지된다
- [ ] "완료 숨기기" · "체크 초기화" 도구 버튼이 패딩 없는 셀형이고 보더가 없다
- [ ] 이날 메모 입력이 저장되고 새로고침 후에도 남는다
- [ ] 시간 칸이 사이드바 톤과 구분되는 카드 톤이다
- [ ] "지도 열기" 링크가 새 탭에서 Google Maps 검색으로 열린다
- [ ] 뷰 전환(`?view=`)이 URL 에 반영되고 뒤로가기가 자연스럽다

## 6. 편집기 (`/trips/[id]/edit`)

- [ ] 탭 스트립이 수평 풀블리드이고 활성 탭만 카드 톤이다(세션 2: 구현이 수평 스트립이라 문구 정정)
- [ ] 각 탭의 폼 컨트롤이 3장의 규칙을 그대로 따른다(보더 없음)
- [ ] 행 추가/삭제가 즉시 반영된다
- [x] dnd-kit 드래그 정렬이 동작하고, 저장 후 순서가 유지된다 — 세션 2: 키보드 정렬(Space·화살표·Space)로 순서 변경 → 토스트 1회 → 새로고침 후 유지, 원복까지 확인. 포인터 드래그는 도구 입력 한계로 미실측
- [x] Cmd+S 로 저장되고 성공 토스트가 1회만 뜬다(중복 토스트 없음) — 세션 2: keydown 1·submit 1·토스트 1. 저장 뒤 재편집이 저장되지 않던 버그를 발견해 수정(ADR-0018)
- [x] 필수값을 비우고 저장하면 필드 오류가 링으로 표시된다 — 세션 2: 제목 비움 → `aria-invalid=true`, 저장 안 됨(라이트·다크 링 확인)
- [ ] JSON 내보내기가 다운로드되고, 같은 JSON 을 가져오기로 되돌릴 수 있다 — 세션 2: 내보내기 토스트 확인. 가져오기는 미구현(ARCHITECTURE §10)이라 보류

## 7. 목적지(나라) 편집기

- [ ] 나라를 여러 개 순서대로 추가/삭제할 수 있다
- [ ] 순서를 바꾸면 목록 헤더 지구본의 경로 순서가 따라 바뀐다
- [ ] 항공편이 없는 트립도 출발지 → 목적지 곡선이 그려진다
- [ ] 도시를 비워도 나라만으로 저장된다
- [ ] 저장 후 새로고침해도 순서가 유지된다

## 8. 즐겨찾기 레일

- [ ] 목록 카드의 즐겨찾기 토글이 즉시 반영된다
- [ ] 레일에 즐겨찾기한 트립만 표시된다
- [ ] 레일 접힘(collapsed) 상태에서도 항목이 깨지지 않는다
- [ ] 해제하면 레일에서 사라지고 새로고침 후에도 유지된다
- [ ] 즐겨찾기가 하나도 없을 때 레일이 빈 영역으로 깨지지 않는다

## 9. 공유 페이지 (`/s/[slug]`)

- [x] 로그아웃 상태(시크릿 창)에서 열린다 — 세션 2: 쿠키 없는 curl 200
- [x] 체크박스·메모 입력이 노출되지 않는다(읽기 전용) — 세션 2: HTML·DOM 모두 checkbox·textarea 0
- [x] 공개를 끈 트립의 slug 는 404 로 간다 — 세션 2: 끄기 → 404, 다시 켜기 → 200
- [x] 트립을 수정한 뒤 공유 페이지에 반영된다(태그 무효화) — 세션 2: 날짜 제목 저장 직후 공유 HTML 에 반영
- [x] 공개 표면(Surface B) 톤이 앱 표면과 섞이지 않는다 — 세션 2: 라이트·다크 스크린샷 확인

## 10. 인쇄 미리보기

- [x] `Cmd+P` 미리보기에서 레일·탭·도구 버튼 등 `print:hidden` 요소가 사라진다 — 세션 2: 스타일시트의 `@media print` 규칙을 화면에 주입해 계산값으로 확인(레일·탭 `display:none`, 인쇄 트리 `flex`). 실제 Cmd+P 창은 자동화 불가
- [x] 전체 날짜가 순서대로 펼쳐져 나온다(활성 날짜만 나오지 않는다) — 세션 2: 인쇄 트리 자식 11개(사이드바·날짜 7·예매·정보·푸터) 순서 확인
- [x] 배경이 흰색, 글자가 검정으로 강제된다 — 세션 2: 다크 모드에서 `bg-card`·보조 텍스트가 다크 토큰으로 인쇄되던 버그 수정(`.dark` 토큰·`dark:` 변형을 `@media screen` 한정) 후 라이트·다크 모두 확인
- [x] 표가 페이지 경계에서 잘리지 않는다 — 세션 2: 표 래퍼·전체 일정 표에 `break-inside-avoid` 추가, 계산값 `avoid` 확인. 실제 페이지 분할 렌더는 미확인

## 11. 모바일 시트

> 세션 2: 폭 500px 창(새 탭 그룹)에서 확인. 탭이 가려져 애니메이션이 진행되지 않아 닫힘·포커스 복귀는 미확정.

- [x] 좁은 화면에서 상단 바 + 시트로 전환된다 — 세션 2: 폭 500px 에서 레일 없이 상단 바(햄버거·Trip·테마)·"탐색 메뉴 열기" 트리거
- [x] 시트에서 트립 이동·계정 메뉴가 모두 동작한다 — 세션 2: 시트(288px)에 트립 목록·새 트립·즐겨찾기 트립·계정 메뉴·닫기 존재, 포커스가 시트 안으로 이동
- [ ] 시트를 닫으면 포커스가 트리거로 돌아온다 — 세션 2: 가려진 탭에서 Escape 후 시트가 남아 미확정(애니메이션 정지). 창을 앞으로 가져와 재확인
- [x] 날짜 스트립·표가 가로 스크롤로만 넘치고 화면을 밀지 않는다 — 세션 2: `/trips/[id]?day=2` 에서 문서 scrollWidth = 뷰포트, 날짜 스트립만 내부 스크롤(678/455)

## 12. 모션 줄이기 토글

- [ ] 계정 메뉴에 "모션 줄이기" 스위치가 테마 토글 아래에 있다
- [ ] 켜면 페이지 전환·리스트 stagger·진행바 트윈이 즉시 정적으로 바뀐다
- [ ] 켠 상태에서 지구본이 자동 회전을 멈춘다
- [ ] 새로고침해도 설정이 유지된다(localStorage `trip-motion`)
- [ ] 끄면 모션이 다시 동작한다
- [ ] OS 의 "동작 줄이기" 설정과 무관하게 앱 설정만 따른다

## 13. 인증·공개 표면

- [x] `/login` · `/signup` 카드가 DESIGN §11-H 대로 보더 + 6px 라운드를 유지한다 — 세션 2: 이름 제거(ADR-0017) 후 헤드리스 Chrome 라이트·다크 촬영으로 `/signup` 확인(사용자명·이메일·비밀번호·확인 4필드, 카드 보더·라운드 유지)
- [ ] 입력이 카드 안에서 보더 없이 `bg-muted` 로 보이고 카드 배경과 구분된다
- [ ] 비밀번호 보기 버튼이 입력 높이(h-8)에 정확히 맞는다
- [ ] 로그인 실패 메시지가 destructive 색으로 1회 표시된다
- [ ] `/` 인트로의 쇼케이스 목록이 보더가 아닌 1px 심으로 나뉜다
- [ ] 존재하지 않는 경로에서 404 화면(지구본 + 두 버튼)이 정상 표시된다
