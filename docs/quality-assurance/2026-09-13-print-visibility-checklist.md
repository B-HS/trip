# 인쇄·공개 설정 QA 메모 (2026-09-13)

## 인쇄 출력 계약

- `전체 일정 인쇄`는 A4 세로(`@page size: A4 portrait`)를 사용합니다.
- 요약(여행 제목·기간·목적지·항공·숙소)을 첫 장에 두고, 각 여행 날짜를 독립된 페이지 래퍼로 출력합니다. 예매 체크리스트와 여행 정보는 날짜 페이지 뒤의 보충 페이지에 배치합니다.
- 날짜 래퍼에는 `break-after: page`를 적용하고, 일정 행·확인 표 행·이동 경로 블록에는 `break-inside: avoid`를 적용합니다.
- 내용이 많은 날짜는 regular → compact → tight 인쇄 밀도로 간격과 글자 크기만 줄입니다. 내용 자체를 숨기거나 고정 높이로 잘라내지 않으므로, 물리적으로 한 장에 담기 어려운 극단적인 날짜는 다음 용지로 자연스럽게 이어집니다.

## 프린터 여백 주의

CSS가 인쇄 가능한 본문에 12mm 여백을 예약해도 실제 프린터의 하드웨어 여백은 더 클 수 있습니다. 인쇄 대화상자에서 용지 크기를 A4로 선택하고, 프린터가 경고하면 `맞춤/축소(Fit/Shrink)`를 사용해야 테두리나 마지막 줄이 잘리지 않습니다. 브라우저의 머리글·바닥글 옵션은 제품 일정과 별개인 브라우저 출력 chrome이므로 필요에 따라 끄십시오.

## 공개 설정 계약

- 여행 상세 화면에서 소유자만 인쇄 버튼 바로 옆의 공개 여부 스위치를 볼 수 있습니다.
- 편집자·열람자·공개 링크 방문자는 스위치를 볼 수 없고, 서버의 기존 `own` 권한 검증을 통해 변경할 수 없습니다.
- 스위치는 서버 저장이 성공한 뒤 쿼리를 갱신합니다. 저장 중에는 비활성화되고 실패 시 마지막으로 확인된 상태를 유지합니다.
