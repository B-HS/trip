# QA 체크리스트 — 커뮤니티·프로필·에디터 (2026-09-10, 세션 3 4단계)

> 개발 서버 `:3000`, Claude in Chrome(탭 줌 54%, 확대 캡처로 확인), 로그인 계정 tester. 입력은 페이지 내 스크립트(native setter + input 이벤트, 합성 keydown, `.click()`)로 넣었다 — 브라우저 자동화의 `type`·`Return` 은 선택 탭·툴바 버튼으로 새어 신뢰할 수 없었다(ADR-0027 실측 메모).
> 비로그인 표면은 headless Chrome 이 멈춰(HANDOFF 의 알려진 증상) 시각 확인을 못 했고 `curl` HTML 로만 확인했다.

## 발견·수정

- ProseMirror `attrs`(null 프로토타입)가 서버 액션에서 `$T` 로 직렬화돼 본문 저장 실패 → `toPlainDocument` 정규화(ADR-0027 실측 메모).
- 링크·YouTube 다이얼로그 폼 제출이 포털을 타고 글 폼까지 버블링 → `stopPropagation`.
