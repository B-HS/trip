# 법률 문서 초안

서비스 이용약관과 개인정보 처리방침의 사용자 화면은 `messages/{ko,en,ja}.json`과 `/terms`, `/privacy` 페이지에 있다. 이 디렉터리에는 검토·보관을 위한 Markdown 초안을 둔다.

현재 버전: `2026-09-12`

초안 파일: `terms.ko.md`·`terms.en.md`·`terms.ja.md`, `privacy.ko.md`·`privacy.en.md`·`privacy.ja.md`.

이 문서는 법률 자문이 아니며, 공개 전 운영자가 법률 검토를 완료해야 한다.
